# Blogy - Full Stack Blogging Platform

A modern blogging platform built with React frontend and Node.js backend.

## Project Structure

- **blogy-frontend/**: React + Vite frontend application
- **blogy-backend/**: Node.js + Express backend API

## Quick Start

### Frontend
```bash
cd blogy-frontend
npm install
npm run dev
```

### Backend
```bash
cd blogy-backend
npm install
npm start
```

## Deployment
- GitHub Actions workflow configured in `.github/workflows/deploy.yml`
- Docker support available for both frontend and backend
